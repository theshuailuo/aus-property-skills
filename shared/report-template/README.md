This folder will hold the shared bilingual HTML report template. The source of truth is the auspptdd report layout; it will be added together with auspptdd once that skill is verified. Until then, new skills output Markdown in this order: conclusion → key facts (with source and retrieval date) → risks → what still needs a person → disclaimer.
