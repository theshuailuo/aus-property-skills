# ATO TR 2026/1:度假屋自用测试

核验日期:2026-10-22(ATO legal database 原文;段落号为 TR 2026/1 的)。一般信息,不是个人税务意见。

## 1. 是什么

- **TR 2026/1** *Income tax: rental property income and deductions for individuals who are not in business*,2026-05-20 署名,终稿(草案 TR 2025/D1,2025-11-12)。取代 IT 2167。
- 配套同日发布:**PCG 2026/3**(s26-50 合规方法,绿 / 黄 / 红区)、**PCG 2026/2**(费用分摊)。
- 适用:个人、不算在经营的出租人(para 5–6)。公司、信托不在范围内。
- 法条:ITAA 1997 **s26-50**(leisure facility)。例外 s26-50(3)(b)(ii):全年「mainly」用于(或持有用于)取得出租收入。
- **过渡**:2026-07-01 之前发生的费用,ATO 不分配合规资源查 s26-50(Appendix 2 para 138,行政安排)。**从 2026-27 财年起真正适用。**有避税、欺诈迹象时不适用过渡(para 139)。

## 2. 两步判断

**第 1 步:是不是「holiday home」**(para 12、30–34、90)
你自己、家人或朋友(免租或低于市价)度假或休闲用、或「留着备用」的房子。按一段时期的使用模式客观判断,空置期也算进去。

**第 2 步:是不是「mainly」用于出租**(para 37–43、104–114)
- 「mainly」= 主要、大部分(para 38)。**不能只比天数**,要看整体(para 40、110)。
- 四个要素(para 41):实际怎么用;用于收入的时间;自用或留着自用的时间;**旺季(学校假期、公共假期、季节高峰)实际能不能订、有没有订出去**。
- 只挂牌不等于 mainly(para 111)。
- **挂牌超过半年,但旺季不放租,说明主要用途不是赚钱**(para 112)。
- 旺季因地而异:海边是夏天,滑雪场是冬天,CBD 看赛事;房主要能客观说明(para 113)。

## 3. 不通过的后果

- **租金照样要报、要交税**(para 125)。
- 跟持有有关的费用**不能扣**(para 35、94–95):para 94 列了贷款利息、council rates、land tax、维修保养,并写明「不限于」。保险、strata 费、水费、借款费用原文没点名,按 para 35「为取得或保有所有权」的范围推断也在内(推断,请会计确认)。不是按比例少扣,是不能扣。
- **仍然能扣**(para 36、96–97、126):平台服务费 / 佣金、广告、booking fees、客人退房清洁等只为出租发生的费用。
- 被否的是扣除本身,不形成可结转的亏损(TR 原文没提结转);唯一去向是 CGT 成本基数第三要素(para 95;s110-25(4)、s110-45(1B)),卖出时少交一点税。等于推迟,不是挽回。
- **折旧(s40-25)和资本工程(Div 43)**:TR 明说不讨论(para 8)。是否同样被否,请问会计。

## 4. 通过之后

还要按 PCG 2026/2 分摊:常用时间法 =(实际出租天数 + 按商业条件真正可订但空着的天数)÷ 365。低价租给亲友也要分摊。

## 6. skill 的粗筛规则(脚本 `ato_screen`)

| 档 | 条件 | 对应 |
|---|---|---|
| 红(likely_fail) | 每年固定屏蔽旺季自住,或拒单 / 取消订单,或非商业条件(定价高于同类、苛刻限制) | PCG para 56 红区因素;TR 例 12、13;PCG 例 9–11 |
| 黄(uncertain) | 旺季自用 8 晚以上但不是每年固定屏蔽(含 ≥ 14 晚),或淡季自用 > 28 晚,或有亲友免费 / 低价入住 | PCG 例 5(旺季自用数月,ATO 也只放黄区)、例 6–7;8 晚这条线是本 skill 自拟 |
| 绿(likely_pass) | 旺季自用 ≤ 7 晚、淡季 ≤ 28 晚、商业条件、不屏蔽旺季 | PCG 例 1–4;TR 例 11 |

这是按 ATO 示例画的线,不是 ATO 的线。ATO 说的是看整体,没有天数门槛,例子「仅作示意、不是行为模板」(PCG 2026/3 para 21)。报告里必须写:「拿你的真实日历,请注册税务代理判断。」

**两件事要分开说**:PCG 的绿 / 黄 / 红是**合规风险分级**(ATO 多大可能来查);TR 的结论是**持有费能不能扣**(是不是「主要用于出租」)。报告里先说风险区,再说「如果被认定为度假屋,后果是……」。

**怎么判「每年固定屏蔽」**:问「是不是每年同样的旺季几周都留给自己?」是,就是 `peak_blocked: true`(PCG para 56 原文:times blocked out for personal use each year)。偶尔某年旺季去住一次,不算。

## 7. 要问用户的(自用日历)

1. 一年大概哪几周自己或亲友去住?落在学校假期、圣诞新年、复活节、长周末的有几晚?
2. 亲友去住收不收钱、按不按市价?
3. 是不是每年同样的旺季几周都留给自己?会不会拒单或取消订单?
4. 定价和推广是不是跟同类房源一样(上主流平台、价格不高于同类、没有苛刻条件)?

## 8. 没查清的(报告里如实写)

- 折旧和资本工程扣除在不通过时的处理(TR para 8 不讨论)。
- Part IVA:TR 和 PCG 都没提,只引用 s26-50(7)(para 44–45)。
- 被否费用进 reduced cost base、以及 2027-07-01 后新 CGT 指数化是否适用第三要素。
